COMMON OPERATIONS

Initialize Data System:
  bash scripts/init_data.sh                    [✅ ALREADY DONE]

Download OS Image:
  cd data/images
  wget https://releases.coreelec.org/CoreELEC-Amlogic.aarch64-latest.img.gz
  gunzip CoreELEC-Amlogic.aarch64-latest.img.gz

Load Configuration:
  source scripts/load_config.sh

Flash Device:
  bash scripts/flash.sh                        [Uses data/images/ automatically]

Deploy Service:
  ./setup_device.sh 192.168.1.XXX              [Logs to data/logs/deployment.log]

View Cache:
  bash scripts/manage_cache.sh show

Check Logs:
  cat data/logs/flashing.log
  tail -f data/logs/deployment.log
