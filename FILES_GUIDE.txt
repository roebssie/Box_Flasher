1. usb_flash_s905w.sh (USB flashing automation)
   Usage: bash usb_flash_s905w.sh
   What it does:
   ├─ Checks prerequisites (libusb, etc.)
   ├─ Downloads CoreELEC image
   ├─ Detects Amlogic device
   ├─ Installs flashing tool

   └─ Flashes device

   Usage: ./setup_device.sh 192.168.1.100
   What it does:
   ├─ Tests SSH connection to device
   ├─ Transfers binary to device
   ├─ Creates systemd service
   ├─ Enables auto-boot
   ├─ Starts service immediately
   └─ Verifies everything works

   When to use: After device boots and is on network

🚀 QUICK START SEQUENCE

1. READ (5 min):
   USB_A_QUICK_START.md

2. PREPARE HARDWARE (10 min):
   ├─ USB-A to USB-A cable
   ├─ USB-C to USB-A adapter (if needed)
   ├─ 5V 2A+ power supply
   └─ Amlogic S905W device

3. FLASH DEVICE (5 min):
   bash usb_flash_s905w.sh
   OR manually follow USB_A_TO_A_FLASHING.md

4. WAIT FOR BOOT (3 min):
   Device appears on network

5. DEPLOY SERVICE (5 min):
   ./setup_device.sh 192.168.1.XXX

6. VERIFY (2 min):
   ssh root@$DEVICE_IP "systemctl status monitor.service"

TOTAL TIME: ~30 minutes (includes device boot time)

🔧 COMMON COMMANDS

Setup (first time):
  brew install libusb libftdi wget
  brew tap messense/amlogic-tools
  brew install amlogic-usb-flashing-tool

Flash device:
  bash usb_flash_s905w.sh

Find device IP:
  ping -c 1 coreelec.local

Deploy service:
  ./setup_device.sh 192.168.1.100

Check service status:
  ssh root@192.168.1.100 "systemctl status monitor.service"

View service logs:
  ssh root@192.168.1.100 "journalctl -u monitor.service -f"

Update binary:
  cmake --build build-aarch64
  ./setup_device.sh 192.168.1.100

💡 TIPS & TRICKS

• Save this guide locally for offline reference
• Keep terminal window open during flashing
• Don't disconnect USB during flashing
• S905W needs 5V 2A+ power during flashing
• Boot button must be held 10-15 seconds
• Wait full 3 minutes for first boot
• If stuck: try different USB port or cable
